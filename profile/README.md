## Who we are

TechNative is a Dutch cloud engineering company (Amersfoort, NL) with two disciplines and one team: **Managed AWS Services** keep your platform reliable and secure, and **FinOps** keeps the costs predictable and transparent. With 100+ AWS launches behind us, we build in the open — what we publish here is the same tooling we run in production for our customers.

We believe friends don't let friends build data centres, and that infrastructure code is better when everyone can read it.

## What you'll find here

### ❄️ ElastiNix — NixOS on AWS

Reproducible NixOS systems for the AWS cloud, plus batteries-included, self-hostable office apps.

- [**elastinix**](https://github.com/wearetechnative/elastinix) — shared build code for our NixOS product family on AWS
- [**terraform-aws-module-elastinix**](https://github.com/wearetechnative/terraform-aws-module-elastinix) — the Terraform side of ElastiNix deployments

### 🏗️ Terraform modules for AWS

50+ reusable modules with security and logging best practices baked in — networking, [Lambda](https://github.com/wearetechnative/terraform-aws-lambda), [ECS](https://github.com/wearetechnative/terraform-aws-ecs), [RDS](https://github.com/wearetechnative/terraform-aws-module-rds-instance), [DynamoDB](https://github.com/wearetechnative/terraform-aws-module-dynamodb), [S3](https://github.com/wearetechnative/terraform-aws-s3), [organization-wide backup](https://github.com/wearetechnative/terraform-aws-organization-backup), [cost anomaly detection](https://github.com/wearetechnative/terraform-aws-module-cost-anomaly-detection), and more. Browse the full catalog on our [open source overview](https://wearetechnative.github.io).

### 🛠️ Tools for cloud engineers

- [**bmc**](https://github.com/wearetechnative/bmc) — AWS utilities for cloud engineers, written in Go
- [**catstack**](https://github.com/wearetechnative/catstack) — loosely coupled Terraform framework that keeps complex infrastructure understandable and scalable
- [**race**](https://github.com/wearetechnative/race) — Terraform tooling for CatStack

### 📄 Quarto publishing

- [**TeXnative**](https://github.com/wearetechnative/TeXnative) — Quarto PDF format for business documents with advanced table rendering
- [**quarto-with-batteries**](https://github.com/wearetechnative/quarto-with-batteries) — a Nix flake packaging everything Quarto needs to render it all
- [**embed-sheet**](https://github.com/wearetechnative/embed-sheet) · [**quarto-content-slots**](https://github.com/wearetechnative/quarto-content-slots) — extensions for spreadsheets and content injection
